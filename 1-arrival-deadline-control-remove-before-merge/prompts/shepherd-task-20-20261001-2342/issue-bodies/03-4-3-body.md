The resolved design uses a serializable CDI `@Named @ViewScoped` editor. It loads only the facade `CargoRoute`, parses the displayed `MM/dd/yyyy` date with a per-load `SimpleDateFormat`, and passes `String` plus `Date` back through the facade. The plan records that the full arrival-deadline string starts with the same date component; keep conversion local and do not add a shared mutable formatter. A malformed stored date must surface as an explicit view/application failure. Only non-null is required; invent no future-date or itinerary chronology policy.

## Implement

Create:

- `demo/src/main/java/org/eclipse/cargotracker/interfaces/booking/web/ChangeArrivalDeadlineDate.java`

Required shape:

```java
@Named
@ViewScoped
public class ChangeArrivalDeadlineDate implements Serializable {
    private static final long serialVersionUID = 1L;

    private String trackingId;
    private CargoRoute cargo;
    private Date arrivalDeadlineDate;

    @Inject
    private BookingServiceFacade bookingServiceFacade;
}
```

Provide `getTrackingId()`, `setTrackingId(String)`, `getCargo()`, `getArrivalDeadlineDate()`, `setArrivalDeadlineDate(Date)`, `load()`, and `changeArrivalDeadline()`.

`load()` must:

1. call `bookingServiceFacade.loadCargoForRouting(trackingId)`;
2. retain the returned `CargoRoute`;
3. parse the DTO's displayed date as `MM/dd/yyyy` with a formatter created for this load;
4. initialize `arrivalDeadlineDate`;
5. surface malformed data clearly and consistently with existing JSF error handling rather than returning null or printing a stack trace.

`changeArrivalDeadline()` must reject null, call `bookingServiceFacade.changeDeadline(trackingId, arrivalDeadlineDate)`, and only after successful return call:

```java
PrimeFaces.current().dialog().closeDynamic("DONE");
```

If practical in the current setup, add a container-free JUnit test with a hand-written facade fake proving correct load identifier, date conversion, delegation, malformed-date failure, and null rejection.

## Completion gates

- The bean compiles, is serializable, and uses the established CDI/JSF annotations under `javax.*`.
- From `demo/`, `./mvnw clean package -Popenliberty` succeeds under Java 17 using the required tee-to-log discipline.
- The bean imports facade DTO/API types but no domain model or repository type.
- Tests or focused inspection prove parsing failure is explicit, null is rejected, facade failure cannot close the dialog, and successful delegation closes with `"DONE"`.
- Any focused test uses a hand-written fake and no new mocking dependency.

## Out of scope

- No dialog launcher, XHTML, dashboard link, repository access, or domain-object access.
- No shared mutable `SimpleDateFormat`.
- No minimum, future, after-old-deadline, or after-itinerary date rule.
- No new command DTO or string-formatted facade command.
- No Jakarta migration, runtime replacement, or broad dependency upgrade.
- No copying code or commits from feature-bearing branches or spike artifacts.
